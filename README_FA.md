# سفارش‌گیر ویزیتور — نسخه آماده Codemagic

این پروژه یک برنامه Android فارسی و آفلاین برای ثبت سفارش ویزیتور است.

## ساخت APK بدون نصب Android Studio
1. محتوای این پروژه را داخل یک GitHub Repository خصوصی قرار دهید.
2. Repository را به Codemagic وصل کنید.
3. Workflow با نام «سفارش‌گیر ویزیتور - APK آماده نصب» را انتخاب کنید.
4. Build را شروع کنید.
5. از بخش Artifacts فایل APK را دریافت کنید.

> این Workflow از `assembleDebug` استفاده می‌کند تا APK خروجی برای نصب و تست مستقیم روی گوشی آماده باشد.

## امکانات نسخه فعلی
- محیط فارسی و راست‌چین
- جست‌وجوی کالا با نام یا کد
- نمایش قیمت، واحد و موجودی
- کنترل و کاهش خودکار موجودی بعد از ثبت سفارش
- ذخیره سفارش‌ها روی گوشی
- تخفیف حجمی و نقدی طبق جدول تعیین‌شده
- حالت نقدی / غیرنقدی
- تاریخچه سفارش‌ها
- لغو سفارش و برگشت موجودی
- ارسال متن سفارش برای حسابداری/انبار
- کارکرد کاملاً آفلاین
